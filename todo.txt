# Project: WeBotApp Security Agency Manager

Build a complete, lightweight Security Agency Management Software using Laravel, MySQL, Livewire and Tailwind CSS.

The application is designed for Indian private security agencies managing security guards, corporate clients, residential societies, offices, factories, shops, warehouses and other security deployment locations.

## 1. UI/UX DESIGN

Create a modern, compact and professional interface.

Design requirements:
- Light background (white and light grey).
- Small typography (12–14px).
- Compact tables and forms.
- Minimal padding and spacing.
- Simple left sidebar navigation.
- Clean dashboard with small information cards.
- Responsive desktop, tablet and mobile layout.
- Avoid gradients, oversized cards and dark themes.
- Easy navigation for non-technical agency owners.

## 20. IMPORTANT DEVELOPMENT RULES

- Build a fully functional application, not just a UI prototype.
- Every button, form, search, filter and action must work.
- Avoid unnecessary complexity.
- Prevent overlapping guard deployments.
- Maintain accurate attendance and payroll calculations.
- Maintain complete payment history.
- Do not permanently delete financial transactions.
- Restrict access to sensitive identity and bank information.
- Log changes to attendance, payroll and deployments.
- Provide confirmation before critical operations.
- Include README and installation instructions.
- Include Docker configuration where practical.
- Provide demo admin credentials through seeders.
- Ensure compatibility with standard Laravel VPS hosting.

## FINAL OBJECTIVE

Deliver a complete, compact and production-oriented Security Agency Management Software for Indian private security agencies.

The application should help agency owners manage guards, clients, deployment sites, duty rosters, attendance, payroll, billing and incidents from one simple dashboard.
